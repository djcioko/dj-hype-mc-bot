# 🔥 DJ HYPE MC BOT

Aplicație Web simplă și rapidă pentru simularea unui MC/DJ de petrecere cu pauze cronometrate între strigăte.

## Caracteristici:
- Redare audio automată (TTS) cu pauză configurată de 3 secunde.
- Salvare automată a textului la repornirea/reîncărcarea paginii (LocalStorage).
- Pregătit direct pentru GitHub Pages.

## Cum publici pe GitHub Pages:
1. Creează un repository pe GitHub (ex: `dj-hype-mc-bot`).
2. Încarcă fișierele `index.html`, `style.css`, `main.js` și `README.md`.
3. Mergi la **Settings** -> **Pages**.
4. La **Source**, selectează `main` branch și `/root`.
5. Apasă **Save**. Aplicația va fi live în câteva momente!
